# Dilsad Modern Landing Page

Light modern, mobile-first landing page with a fixed glass navbar, swipeable hero photos, offer section, Hinglish WhatsApp process, achievements, photo gallery, team feedback and 16:9 video-feedback uploader/slider.

## Video feedback
The feedback uploader previews selected videos in the browser. For permanent uploads from the admin panel, connect `#feedbackVideos` to the existing PHP upload/CRUD system and save the returned video paths.

## WhatsApp
Open `site/js/script.js` and replace `WHATSAPP_NUMBER` with the real number (country code + number, no `+` or spaces).
